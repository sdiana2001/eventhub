# EventHub: frontend

Интерфейс афиши мероприятий: React, TypeScript, Vite, Redux Toolkit.

## Запуск
1. Сначала запусти бэкенд (см. README в `eventhub-be`), он должен работать на `http://localhost:3000`.
2. Установи зависимости и запусти:
```bash
   npm install
   npm run dev
```
3. Открой адрес из терминала, обычно `http://localhost:5173`.

Адрес бэкенда сейчас прописан прямо в коде (`http://localhost:3000`).
